Every release of Kito is on GitHub, with an archive for each platform
(`linux-x86_64`, `linux-aarch64`, `macos-arm64`, `macos-x86_64`,
`windows-x86_64`), its SHA-256 checksum, and the release notes:

- **Kito**: [github.com/KitoOrg/kito/releases](https://github.com/KitoOrg/kito/releases)

The [install script](../install/) takes the latest one for you.

## Plugins

Each plugin is released from its own repository. `kito plugin add <name>`
and `kito-server plugin add <name>` find it by name and fetch it from
there, checked against the checksum the registry gives.

| Plugin | Releases |
| --- | --- |
| Web client | [KitoOrg/kito-web](https://github.com/KitoOrg/kito-web/releases) |
| GitHub | [KitoOrg/kito-github](https://github.com/KitoOrg/kito-github/releases) |
| OpenID Connect | [KitoOrg/kito-oidc](https://github.com/KitoOrg/kito-oidc/releases) |
| Kitchen | [KitoOrg/kito-kitchen](https://github.com/KitoOrg/kito-kitchen/releases) |
| Claude Code | [KitoOrg/kito-claude](https://github.com/KitoOrg/kito-claude/releases) |
| Codex | [KitoOrg/kito-codex](https://github.com/KitoOrg/kito-codex/releases) |
| ZCode | [KitoOrg/kito-zcode](https://github.com/KitoOrg/kito-zcode/releases) |
