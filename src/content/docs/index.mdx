## What it looks like

```bash
kito lane open alice --intent "taxes on every total" --scope src/shop.ts:total
# … the agent edits the files of its lane …
kito integrate lane/1
```

```text
lane/1: integrated as ckpt#2 (git 78ff4e73aa), verified in 2.1 s
```

Kito runs on Linux and macOS (on Windows, in WSL). It works with Claude Code
and any agent that speaks MCP. [Install it](/install/), then follow
[First steps](/getting-started/first-steps/).
