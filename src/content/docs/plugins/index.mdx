Kito has no web view, no sign-on and no knowledge of your coding assistant
built in. Each of those is a **plugin**: a separate program named
`kito-<name>`, with a manifest (`kito-plugin.toml`) that says what it asks
for and what it adds.

Nothing of a plugin runs unless a repository or a server enabled it, and it
gets only the permissions it was given.
